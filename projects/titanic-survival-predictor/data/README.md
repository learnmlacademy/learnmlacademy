# Put Kaggle's train.csv here

Download the Titanic competition data personally from
https://www.kaggle.com/competitions/titanic/data after reviewing its rules.
Extract the downloaded archive. Copy **train.csv** into this folder, keeping
the filename unchanged. Do not copy test.csv over it.

Expected training file: 891 rows and 12 columns, including Survived.
The CSV is intentionally not redistributed with this project.
