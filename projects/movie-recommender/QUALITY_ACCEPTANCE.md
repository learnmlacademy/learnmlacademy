# Movie Recommendation System — Learning Value Acceptance

This free flagship project must be strong enough to make the premium LearnMLAcademy projects credible.

## Required learner outcomes

A learner must be able to explain:

- why recommendation output is a ranked list,
- why a popularity baseline matters,
- why shrinkage helps tiny-rating-count items,
- how repeat user/movie ratings are handled,
- how genre + decade become content labels,
- how cosine nearest-neighbour search works,
- what a sparse movie-user matrix stores,
- how item-item collaborative similarity differs from content similarity,
- what the 45/55 hybrid score means,
- what cold start means,
- why offline recommender evaluation needs a held-out ranking protocol,
- what synthetic data changes about interpretation,
- what a production recommender would add.

## Dataset/licence gate

The current implementation uses Datanemics Movie ratings:

- synthetic
- CC0 1.0 public domain
- 9,000 rows
- 1,100 users
- 260 movie IDs

Do not present synthetic recommendations as evidence about real people or real audience preferences.

## Final gate

Required:

- reproducible data download and schema/count validation
- executable recommendation code
- deterministic reference example
- saved/reloaded artifact
- automated behavioral tests
- cold-start fallback with 0–1 compatible score
- sparse-matrix checks
- genuine app screenshots
- generated rating-distribution chart
- complete copyable source in the handbook
- learner exercises
- troubleshooting
- interview explanation
- production limitations
- mastery questions
- route/catalog/SEO/sitemap integration
- TypeScript validation
- production build/prerender
- desktop/mobile verification
- no horizontal overflow
