# Netflix-Style Movie Recommendation System

This project is being built as the third free LearnMLAcademy flagship project.

Dataset source: MovieLens latest-small from GroupLens.

The final project will compare a popularity fallback, content-based similarity, collaborative movie-neighbor similarity and a simple hybrid ranker, then expose the system through Streamlit.

This branch is a working build. Do not treat it as the published handbook until the full verification gate passes.
